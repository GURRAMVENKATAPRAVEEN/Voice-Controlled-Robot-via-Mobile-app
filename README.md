# Voice-Controlled Robot via Mobile App

## 1. Project Overview
The Voice-Controlled Robot is an Arduino-based robotic system that uses Bluetooth communication to receive commands from a mobile application. The robot can move forward, backward, left, right, and stop according to the voice commands given by the user.

This project demonstrates the practical applications of robotics, embedded systems, Arduino programming, and wireless communication.

## 2. Aim
To design and develop a robot that can be controlled through voice commands using a mobile application and Bluetooth communication.

## 3. Components Required
- Arduino UNO
- Bluetooth Module (HC-05 or HC-06)
- Motor Driver Module (L298N)
- DC Gear Motors
- Robot Chassis and Wheels
- Battery
- Jumper Wires
- Android Mobile Phone
- Voice-Controlled Robot Application

## 4. Working Principle
The user gives voice commands through a mobile application. The application converts the voice commands into corresponding control instructions and sends them to the Bluetooth module.

The Bluetooth module transfers these instructions to the Arduino UNO. The Arduino processes the received commands and controls the motors through the motor driver module.

Based on the received commands, the robot moves forward, backward, left, or right, or stops.
